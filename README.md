# 3D Ear & Head Spatial Audio Scanner (iOS Face ID TrueDepth)

Нативное приложение для iOS, использующее аппаратный блок сенсоров **Face ID (TrueDepth)** для трехмерного сканирования ушных раковин и головы с целью создания персонализированного профиля пространственного звука (HRTF / SOFA) на ПК.

---

## Возможности и логика работы
1. **Сенсор Face ID (TrueDepth):** Захват метрической карты глубины через инфракрасный проектор точек и синхронизированный RGB-сенсор в рамках сессии `ARFaceTrackingConfiguration`.
2. **Пошаговый сценарий сканирования:**
   - **Центр:** Телефон удерживается перед лицом на расстоянии 35–45 см.
   - **Поворот влево:** Голова плавно поворачивается влево (сенсор сканирует профиль и ухо).
   - **Поворот вправо:** Голова поворачивается вправо (сенсор сканирует противоположный профиль и ухо).
3. **Голосовой и тактильный ассистент (`AVSpeechSynthesizer`):** При повороте головы экран не виден, поэтому приложение озвучивает команды на русском языке и подтверждает захват каждого ракурса звуком и вибрацией.
4. **Автоматическое выравнивание:** Все три ракурса трансформируются в единую систему координат головы (`ARFaceAnchor.transform`), формируя монолитную 3D-модель.
5. **Экспорт без ограничений:** Автоматическая сборка в единый `SpatialAudio_EarScan_<timestamp>.zip` и вызов нативного меню «Поделиться», а также сохранение в директорию `Documents` для прямого копирования по USB через ПК.

---

## Содержимое сформированного ZIP-архива
- `ear_head_scan.obj` — стандартная 3D-модель (Wavefront OBJ) с цветами вершин для импорта в Blender, MeshLab, CloudCompare, Mesh2HRTF.
- `ear_head_scan.ply` — цветное облако точек (Stanford Triangle PLY) с точными миллиметровыми координатами `x, y, z` и цветами `r, g, b`.
- `front_face.jpg` — фронтальный снимок высокого разрешения.
- `turn_left_ear.jpg` — снимок левого ушного профиля.
- `turn_right_ear.jpg` — снимок правого ушного профиля.
- `scan_metadata.json` — метаданные калибровки, метрические габариты (bounding box), число вершин и модель устройства.

## Сборка и запуск на iPhone

### Вариант 1: Сборка через Xcode на Mac
1. Откройте файл `EarSpatialAudioScanner.xcodeproj` в Xcode.
2. В разделе **Signing & Capabilities** выберите вашу команду (Personal Team с бесплатным Apple ID или Developer Account).
3. Подключите iPhone по проводу или Wi-Fi, выберите устройство в списке и нажмите **Run** (Cmd + R).

### Вариант 2: Установка без Mac (Sideloading / AltStore / SideStore / TrollStore)
- Соберите файл `.ipa` через Xcode (`Product -> Archive -> Distribute App`) или сторонний сервис подписи, либо перенесите исходные файлы в **Swift Playgrounds** на iPad/iPhone.

---

## Получение архива на ПК

1. **По воздуху:** Сразу после завершения сканирования откроется меню «Поделиться». Выберите Telegram, сохранение в iCloud Drive, Google Drive или отправку по почте.
2. **По проводу USB:**
   - Подключите iPhone к ПК с Windows через USB-кабель.
   - Откройте приложение **Apple Devices** (или **iTunes** / **3uTools**).
   - Перейдите в раздел **Общий доступ к файлам** (File Sharing) -> выберите **EarScanner**.
   - В списке файлов найдите архив `SpatialAudio_EarScan_*.zip` и перетащите его в любую папку на ПК.
